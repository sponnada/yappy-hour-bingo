# Zero-auth static hosting settings

Use these values in a hosting provider’s deployment form:

| Setting | Value |
|---|---|
| Framework preset | None / Static HTML |
| Root or app directory | This folder |
| Build command | None |
| Output or publish directory | This folder (`.`) |
| Serverless functions | None |
| Authentication | Disabled / not configured |
| Environment variables | None |
| HTTPS | Required for offline/PWA support |

No identity provider, API key, Microsoft 365 connection, Teams app registration, SharePoint site, or tenant permission is required.
